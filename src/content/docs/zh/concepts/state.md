## 你送进去的是什么

**状态**是 clavue-jev 要判定的文本。在 `POST /v1/judge` 里它是一段字符串，8 到 4000 个字符。同一次请求里的每个问题都看这段字符串，问题之间不读彼此的答案。

把判定需要的事实写进这段文字：那条消息、那句政策、你要比较的两个名字。没写进去的事实，模型就没有。

```json
{
  "state": "用户：我被扣了两次。政策：7 天内的重复扣款可以退。扣款：周二 18:02、周二 18:04，同一张卡，同一金额。",
  "questions": {
    "duplicate": {
      "type": "noul",
      "instructions": "这几行是不是重复扣款？"
    }
  }
}
```

## 一段状态，几个问题

互相独立的问题放在同一次请求里，最多六个。「是不是重复扣款」和「进哪个队列」可以一起走。如果后一题要读前一题的答案，就再调一次，把第一次的答案写进新的状态。

一段里有好几件事实时，给它们起名字。「政策：… 扣款：…」比三团没有标签的文字更容易判。

## 长度

短于 8 个字符会被拒绝。长于 4000 个字符会被拒绝。材料放不下时，裁到这道题真正要用的几行，或者拆成两次调用。
