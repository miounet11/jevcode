## JevCode

JevCode est la maison de Jev. Le modèle de ce site est **clavue-jev**. Nous l'avons construit, nous le servons, et nous le tenons pour le meilleur Jev au monde aujourd'hui.

jev-1.13.0 apparaît sur la page de comparaison, pour la même question. Ce n'est pas le modèle que ce site propose.

clavue-jev n'est pas un modèle de chat. Vous envoyez un **état** et jusqu'à six **questions typées**. Il renvoie des champs qu'un programme peut lire.

| Question | Retour |
| :--- | :--- |
| `noul` | Nombre de 0 à 1. À quel point la réponse est oui. |
| `confidence` | Nombre de 0 à 1. À quel point le jugement tient. |
| `choice` | L'une des options que vous avez envoyées. |
