## JevCode

JevCode は Jev の本拠です。このサイトのモデルは **clavue-jev** です。私たちが作り、私たちが提供し、今日世界で最も優れた Jev として出しています。

jev-1.13.0 は比較ページに出ます。同じ質問に答える対照であり、このサイトが提供するモデルではありません。

clavue-jev はチャットモデルではありません。**状態**と、最大六つの**型付き質問**を送ると、プログラムが読めるフィールドが返ります。

| 質問 | 戻り値 |
| :--- | :--- |
| `noul` | 0 から 1 の小数。「はい」の強さ。 |
| `confidence` | 0 から 1 の小数。その判定がどれだけ確かいか。 |
| `choice` | あなたが挙げた選択肢の一つ。 |
