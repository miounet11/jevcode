## 送るもの

**状態**は clavue-jev が判定するテキストです。`POST /v1/judge` では 8 から 4000 文字の文字列ひとつです。同じリクエストの質問はすべてこの文字列を見ます。質問同士は相手の答えを読みません。

判定に必要な事実をその文字列に入れてください。そのメッセージ、そのポリシーの一行、比べたい二つの名前。書いていない事実は、モデルにはありません。

```json
{
  "state": "ユーザー：二重に請求された。ポリシー：7 日以内の重複請求は返金対象。請求行：火曜 18:02、火曜 18:04、同じカード、同じ金額。",
  "questions": {
    "duplicate": {
      "type": "noul",
      "instructions": "この行は重複請求を示していますか？"
    }
  }
}
```

## ひとつの状態、いくつもの質問

独立した質問は同じリクエストに、最大六つまで置けます。「重複請求か」と「どのキューか」は一緒に送れます。前の答えが必要な質問は一緒に送れません。その場合は二回目の呼び出しにして、一回目の答えを新しい状態に書いてください。

事実が複数あるときは、本文の中でそれぞれに名前を付けてください。「ポリシー：… 請求行：…」は、ラベルのない三つの塊より判定しやすくなります。

## 長さ

8 文字未満は拒否されます。4000 文字を超える場合も拒否されます。材料が収まらないときは、その質問に本当に必要な行だけ残すか、二回の呼び出しに分けてください。
